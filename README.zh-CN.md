# 伪装方块遮光补丁 / Copycat Light Control

适用于 Minecraft 1.21.1、NeoForge、Create 6.0.x、Copycats+ 3.0.9。
这是独立附属模组，安装后仍须保留 Create 和 Copycats+。

## 使用

将 `copycat-light-control-0.2.1.jar` 放入实例的 `mods` 目录，并移除旧版补丁。多人游戏需要客户端安装才能得到表面光照修正，服务端安装用于材质遮光计算。
不需要替换 Copycats+ 原 JAR，也不需要重新放置已有方块；加载方块实体时会刷新光照。

- 石头、木板、金属等不透明填充材质：整格遮挡方块光和天空光。
- 普通玻璃、染色玻璃：透光。其他材质使用自身的原版遮光值，例如树叶保留光照衰减。
- 遮光玻璃：保持原版遮光效果，视觉透明不代表透光。
- 没有填充材质的伪装方块：遮光。
- 多材质方块：取实际存在部件中最大的遮光值；一个部件不透明，整个格子遮光。不存在的部件不参与判断。
- Create 原生伪装面板、伪装台阶一并支持。
- 保留原模组发光材质的发光功能；不会改变模型、碰撞、贴图或面剔除。
- 修正台阶、薄板、楼梯等内缩面从自身遮光格采到零亮度的问题：按面的法线读取邻侧光照，保留方向阴影与环境光遮蔽（AO）。普通方块不做增亮。
- Sable 物理体：缓存封闭车厢的内外分区。不透明伪装车壳的内面保留车内光；外面使用主世界车外灯光，避免窗口漏出的车内灯光把外壳照亮。玻璃和发光填充单独处理。

采用“整格由材质决定遮光”的规则，因此薄板、楼梯、门等填入不透明材质后，所在格子的几何空隙也会挡光。
这是本补丁的设计行为，用于避免薄伪装方块搭建的建筑漏光。

## 存档与性能

0.2.1 修复 0.2.0 的 Sodium FRAPI 区块网格崩溃：普通方块提前跳过，不再读取它们的贴图；伪装方块使用 FRAPI 支持的缓存贴图接口。没有缓存贴图时保留逐面采光，避免调用会抛出异常的 `QuadViewImpl.getSprite()`。

不注册新方块、物品或数据组件，不更改 Copycats 的材质 NBT，也不迁移已有方块。
遮光快照仅存于内存，区块卸载时清理。实际光照仍由 Minecraft 的光引擎计算。
安装和更换材质时会产生正常的局部光照更新。卸载后方块和填充物仍由原模组读取；光照恢复可能需要区块重算。

0.1.1 增加 Sable 2.0.6 独立物理体光照引擎兼容，填充物更换和加载后会更新物理体自己的光照，而非仅更新主世界。
已在真实 Sable plot 中验证封闭车壳外侧无方块光、玻璃窗口透光、重新封窗清除外部光照。

0.2.0 的车壳内外处理属于客户端显示规则，光引擎仍允许玻璃透光；它不会更改其他方块接收到的真实光照。外壳保留天空光与 Sable 自身的天空光缩放，不设置统一的最低亮度。黑夜无光处自然较暗。

分区只在物理体封闭性、材质、包围盒或区块装载变化时重算，每刻最多读取 4096 个格子；读取完后进行一次最多 262144 格的洪水填充，该步骤不会继续分刻。超出此体积上限会回退到普通逐面采光。玻璃在分区上视为车厢边界，但照明仍透明。打开的门洞或车壳缺口会让空气连通，可能将车内归为外部；复杂镂空结构采用格子级近似。

车外块光在客户端主线程分批采样，每刻最多 510 次，空闲时每 10 刻发起下一轮；大型车辆可能需要更久才能更新。只有外部光照变化的渲染区段会重新编译。渲染工作线程只读不可变快照，不逐面遍历车厢。普通非伪装方块不受影响。

已验证原版客户端普通／平滑光照管线的六方向内缩面采光。Sable 2.0.6 的 `SODIUM_REACHAROUND` 实际也经过原版管线；普通世界另外提供 Sodium 0.8.13 兼容。光影包自行添加的动态光、泛光、光追不一定遵循此显示规则；最终整车画面仍需游戏内复测。

## 构建

使用 Java 21、Gradle Wrapper。`libs/` 中放入本地开发依赖：

```
copycats-3.0.9+mc.1.21.1-neoforge.jar
create-1.21.1-6.0.10.jar
flywheel-neoforge-1.21.1-1.0.6.jar
ponder-neoforge-1.0.82+mc1.21.1.jar
Registrate-MC1.21-1.3.0+67.jar
```

```powershell
$env:JAVA_HOME = 'D:/Program Files (x86)'
$env:GRADLE_USER_HOME = 'D:/GradleCache'
.\gradlew.bat --offline --no-daemon clean build
```

输出位于 `build/libs/`。普通构建不包含 `src/smoke/` 的服务端测试代码。
`tools/verify.ps1` 在项目的独立 `run-smoke/` 世界进行服务端验证，不接触游戏实例的存档。
Sable 为可选依赖；构建时在 `optional-libs/` 放置 Sable 2.0.6、Sable Companion 1.6.0 和 Sable Rapier 本地开发 JAR。
`compile-libs/` 放置 Sodium 0.8.13 的内部 mod JAR、其捆绑的 Fabric Renderer API 与 Fabric API Base，仅用于编译，不打包或强制安装 Sodium。
`tools/verify.ps1 -Sable` 追加 `src/sableSmoke/` 的真实物理体照明测试；这些依赖与测试代码均不进入发布包。
依赖 JAR 不打包进发布物；Copycats+、Create 及其他依赖保留各自许可证。
`tools/verify-enclosure.ps1` 测试封闭空间算法；`tools/verify-client.ps1` 使用隐藏窗口和独立配置验证真实客户端渲染管线，不连接用户世界。发布前须普通 `clean build`，清除测试类与临时测试 Mixin。
